
# Tracking And Managing Project Task

A full-stack task management web application designed to improve productivity, workflow organization, and team collaboration. The system provides secure role-based access for Admin and User roles, allowing efficient task creation, assignment, tracking, and performance monitoring through interactive dashboards and real-time updates.

## Demo

https://tracking-and-managing-project-task.onrender.com

## 🌐 Environment Variables

Create a `.env` file inside the `backend` directory and add the following:

PORT=5000

JWT_SECRET=your_secret_key

## ✨ Features

- 🔐 Secure Login & Signup Authentication
- 👨‍💼 Role-Based Access Control (Admin/User)
- 🎟️ Admin Invite Token System
- 📋 Task Creation & Assignment
- 📌 Task Priority Levels (Low, Medium, High)
- 📅 Due Date Management
- ✅ Checklist Management for Tasks
- 📎 File & Attachment Upload Support
- 📊 Admin Dashboard with Analytics
- 📈 User Dashboard with Progress Tracking

- 📉 Pending & Completed Task Monitoring
- ⚡ Real-Time Task Updates
- 🛡️ JWT Authentication & Protected Routes

- 📱 Responsive & User-Friendly Interface
